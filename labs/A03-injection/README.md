# A03: Injection

## Objective

Understand how untrusted input can alter commands, queries, interpreters, or application behavior.

## Scope

- Platform:
- Lab or room:
- Target URL:
- Injection point:

## Key Concepts

- SQL injection
- Command injection
- NoSQL injection
- LDAP injection
- Template injection
- Cross-site scripting

## Tools

- Burp Suite
- Browser developer tools
- curl
- sqlmap for authorized labs only

## Workflow

1. Map input points.
2. Establish baseline responses.
3. Send controlled payloads.
4. Confirm behavior with minimal impact.
5. Capture evidence in `screenshots/`.
6. Record findings and remediation.

## Checklist

- [ ] Input points mapped
- [ ] Baseline captured
- [ ] Payloads tested
- [ ] Screenshots captured
- [ ] Remediation written
