# ─────────────────────────────────────────────
# RECON — Service and Header Fingerprinting
# ─────────────────────────────────────────────

# Port and service scan
nmap -sC -sV <TARGET_IP>

# Response header inspection
curl -I http://<TARGET_IP>:<PORT>/

# Headers to look for:
#   Server: (framework/version disclosure)
#   X-Powered-By: (runtime disclosure)
#   X-Frame-Options: (missing = clickjacking risk)
#   Content-Security-Policy: (missing = XSS risk)
#   Strict-Transport-Security: (missing = downgrade risk)
