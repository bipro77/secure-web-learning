# A05: Security Misconfiguration

## Objective

Identify unsafe defaults, exposed services, verbose errors, and missing hardening controls.

## Scope

- Platform:
- Lab or room:
- Target URL:
- Component:

## Key Concepts

- Default credentials
- Verbose errors
- Exposed admin interfaces
- Missing security headers
- Unnecessary services or features

## Tools

- Browser developer tools
- Burp Suite
- curl
- nmap for authorized targets only

## Workflow

1. Identify exposed surfaces and configuration clues.
2. Review headers, errors, methods, and default paths.
3. Test for unnecessary functionality.
4. Capture evidence in `screenshots/`.
5. Record findings and remediation.

## Checklist

- [ ] Headers reviewed
- [ ] Error handling reviewed
- [ ] Default paths checked
- [ ] Screenshots captured
- [ ] Remediation written
