# A09: Logging and Monitoring Failures

## Objective

Evaluate whether security-relevant events are logged, monitored, and actionable.

## Scope

- Platform:
- Lab or room:
- Target URL:
- Events tested:

## Key Concepts

- Missing security logs
- Incomplete audit trails
- Poor alerting
- Log injection
- Delayed incident detection

## Tools

- Application logs
- Browser developer tools
- Burp Suite
- SIEM or logging dashboard when available

## Workflow

1. Identify security-relevant events.
2. Trigger controlled events in scope.
3. Check whether logs capture who, what, when, where, and outcome.
4. Capture evidence in `screenshots/`.
5. Record findings and remediation.

## Checklist

- [ ] Events identified
- [ ] Logs reviewed
- [ ] Alerting reviewed
- [ ] Screenshots captured
- [ ] Remediation written
