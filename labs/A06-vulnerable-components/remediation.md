# Remediation: A06 Vulnerable Components

## Root Cause

Document why the outdated or vulnerable component remained in use.

## Recommended Fixes

- Maintain an accurate software bill of materials.
- Remove unused dependencies.
- Update vulnerable components to fixed versions.
- Subscribe to security advisories for critical dependencies.
- Automate dependency scanning in CI.

## Verification

1. Confirm the vulnerable version is no longer present.
2. Re-run dependency scanning.
3. Re-test the affected behavior.
4. Add upgrade and monitoring ownership.
