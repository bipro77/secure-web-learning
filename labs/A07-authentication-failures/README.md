# A07: Authentication Failures

## Objective

Understand weaknesses in login, session handling, identity proofing, and credential recovery.

## Scope

- Platform:
- Lab or room:
- Target URL:
- Account types:

## Key Concepts

- Weak credential policies
- Broken session management
- Credential stuffing exposure
- Insecure password reset
- Missing multi-factor protections

## Tools

- Browser developer tools
- Burp Suite
- curl

## Workflow

1. Map authentication and recovery flows.
2. Review session and cookie behavior.
3. Test rate limits and account protections in scope.
4. Capture evidence in `screenshots/`.
5. Record findings and remediation.

## Checklist

- [ ] Auth flows mapped
- [ ] Session behavior reviewed
- [ ] Reset flow reviewed
- [ ] Screenshots captured
- [ ] Remediation written
