# Scripts

Small helper scripts can live here when they support authorized lab documentation, local parsing, or repeatable defensive analysis.

## Rules

- Keep scripts scoped to local or authorized lab use.
- Do not include credentials, tokens, target IP addresses, or session data.
- Do not commit automation that targets third-party systems.
- Prefer clear documentation over complex tooling.

## Examples of Acceptable Use

- Formatting sanitized notes.
- Parsing local exported sample data after sensitive fields are removed.
- Generating local checklists.
- Validating repository structure.
