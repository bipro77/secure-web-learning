# Tools

Track tools used for authorized cybersecurity learning and defensive analysis.

## Tool Index

| Tool | Purpose | Notes |
| --- | --- | --- |
| Browser developer tools | Inspect requests, responses, storage, and client behavior | Use only with authorized labs |
| Burp Suite Community | Intercepting proxy and request replay | Do not commit raw project files or proxy history |
| curl | Reproducible HTTP request examples | Sanitize headers, cookies, and tokens |
| OWASP Juice Shop | Intentionally vulnerable practice app | Use local or authorized instances |
| PortSwigger Web Security Academy | Web security labs | Store only sanitized writeups |
| TryHackMe | Guided cybersecurity labs | Store only sanitized learning notes |

## Documentation Standard

When adding a tool note, include:

- Tool purpose
- Lab context
- Safe configuration notes
- Data that must not be committed
